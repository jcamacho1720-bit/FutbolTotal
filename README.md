# Fútbol Total / Bogotá Elite Pro ⚽🔥

Aplicación web móvil para la gestión de reservas de canchas de fútbol sintéticas, organización de partidos con amigos y comunidad deportiva.

## 🚀 Características actuales
- **Selector de Fechas dinámico:** Calendario horizontal interactivo para buscar partidos día a día.
- **Listado y Detalle de Canchas/Partidos:** Visualización de horarios, cupos disponibles, fotos y especificaciones de las canchas (iluminación LED, gramilla FIFA, duchas, etc.).
- **Calculadora de Extras y Pagos:** Selección de complementos (hidratación, fotografía, canilleras) con cálculo en tiempo real.
- **Mockups de Pantallas:** Módulo de Chat grupal y Perfil de jugador.
- **Diseño Móvil Moderno:** Modo oscuro con toques neón (#ccff00) y dorado (#D4AF37).

## 🛠️ Tecnologías
- HTML5
- CSS3 (Vanilla / Dark mode UI)
- JavaScript (Vanilla)

## 📦 Cómo ejecutar localmente
Simplemente abre el archivo `index.html` en tu navegador preferido o usa una extensión como Live Server en VS Code.
